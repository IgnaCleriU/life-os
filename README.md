# Life OS

A personal operating system for projects and tasks, notes, calendar,
passwords and home inventory, usable by its owner and by AI agents.

The project is being **rebuilt from zero**:

- [`new/`](new/README.md): the active project.
- [`deprecated/`](deprecated/DEPRECATED.md): the previous version, frozen. It
  has bad practices and discarded decisions. Do not use it as a base.
